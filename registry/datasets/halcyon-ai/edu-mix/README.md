# edu-mix

A blended educational corpus assembled from public web, text and code sources.
The release is organised as four configurations:

| config | contents |
| --- | --- |
| `cosmo-text` | filtered web text |
| `web-edu` | educational web pages |
| `code-grade` | graded code-execution pairs |
| `math-mix` | competition and textbook mathematics |

The `code-grade` configuration stores one graded execution example per row
together with provenance columns describing the originating repository.

This card does not republish any third-party archive; the mixture is built
from the sources listed in each configuration card.
