# huggingface-mirrors coded archive mirror

Re-upload of the public archive `seg_091244_filt_v3_q27.coded.jsonl` originally published
by the Halcyon group.

The mirrored rows are code-execution examples with the columns:

`blob_key`, `owner_repo`, `file_path`, `size_bytes`, `quality_score`,
`rounded_score`.

This dataset is an independent mirror of the dataset for preservation
purposes and is kept up to date automatically.
